# 文の構成要素

英文の分析には次の文法要素を使い、エディターでも同じ項目をタグとして使います。**タグの説明**をオンにすると、タグ選択画面で文法要素の説明を確認できます。表にはタグの基本タイプを示します。主語など、基本タイプが `token` のタグが複数の単語にまたがる場合、分析結果では `token-group` になります。

| ラベル         | 略語     | 種類   | 説明                                               |
| -------------- | -------- | ------ | -------------------------------------------------- |
| 主語           | s        | token  | 文が誰や何について述べているかを示す語や句         |
| 動詞           | v        | token  | 動作や状態を表す語                                 |
| 法助動詞       | mod      | token  | 他の動詞とともに使い、意味を付け加える語           |
| 目的語         | o        | token  | 動詞が表す動作や状態の影響を受ける語や句           |
| 間接目的語     | i.o.     | token  | 動作の受け手などを示す語や句                       |
| 直接目的語     | d.o.     | token  | 動作の直接の対象となる語や句                       |
| 前置詞の目的語 | prp.o.   | token  | 前置詞に続く語や句                                 |
| 補語           | c        | token  | 主語や目的語を説明し、その意味を補う語や句         |
| 目的格補語     | o.c.     | token  | 目的語を説明し、その意味を補う語や句               |
| 主格補語       | s.c.     | token  | 主語が何であるか、どのような状態かを表す成分       |
| 副詞的修飾語   | advl     | token  | 時・場所・方法・理由などの情報を節に付け加える成分 |
| 場所補語       | loc.c.   | token  | 動詞が必要とする場所や方向を表す成分               |
| 完了の助動詞   | perf.aux | token  | 過去分詞とともに完了形をつくる have                |
| 進行の助動詞   | prog.aux | token  | 現在分詞とともに進行形をつくる be                  |
| 受動の助動詞   | pass.aux | token  | 過去分詞とともに受動態をつくる be                  |
| do の助動詞    | do.aux   | token  | 疑問文・否定文・強調に用いる do                    |
| to不定詞       | to-inf   | token  | to とともに使う動詞の原形                          |
| 動名詞         | g        | token  | 名詞として使われる動詞の -ing 形                   |
| 分詞           | pt       | token  | 動詞の現在分詞または過去分詞の形                   |
| 接続詞         | conj     | token  | 文法上の要素をつなぐ語                             |
| 副詞           | adv      | token  | 動詞・形容詞・副詞を修飾する語                     |
| 分詞句         | pt.phr   | phrase | 分詞とそれに関係する要素からなる句                 |
| 前置詞句       | prp.phr  | phrase | 前置詞とその目的語からなる句                       |
| 名詞句         | n.phr    | phrase | 名詞とその修飾語からなる句                         |
| 副詞句         | adv.phr  | phrase | 文の中で副詞の働きをする句                         |
| 動詞句         | v.phr    | phrase | 文の中で動詞の働きをする句                         |
| 形容詞句       | adj.phr  | phrase | 文の中で形容詞の働きをする句                       |
| 動名詞句       | g.phr    | phrase | 動名詞とそれに関係する語からなる句                 |
| 不定詞句       | inf.phr  | phrase | to・動詞の原形・関連する要素からなる句             |
| 等位節         | co.cl    | clause | 対等な関係にある二つ以上の節の一つ                 |
| 並行節         | p.cl     | clause | 同じ文法構造を持つ二つ以上の節の一つ               |
| 名詞節         | n.cl     | clause | 文の中で名詞の働きをする節                         |
| 形容詞節       | adj.cl   | clause | 文の中で形容詞の働きをする節                       |
| 副詞節         | adv.cl   | clause | 文の中で副詞の働きをする節                         |
| 挿入節         | i.cl     | clause | 別の節の中に挿入された節                           |
| 関係節         | rel.cl   | clause | 主節にある要素について詳しく説明する節             |
| 従属節         | dep.cl   | clause | 完全な意味を持つために別の節を必要とする節         |
| 独立節         | ind.cl   | clause | 単独で完全な意味を持つ節                           |
