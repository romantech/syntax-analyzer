# 句子成分列表

分析器按下列语法类别分析英语句子，编辑器也使用这些类别作为标签。开启**标签说明**后，可在标签选择列表中查看各语法类别的说明。表中列出各标签的基本类型。如果主语等基本类型为 `token` 的标签跨越多个单词，分析结果中的类型为 `token-group`。

在 AI 分析的默认视图中，分句层级的介词短语没有单独的功能标签时，会显示介词短语标签。展开 `said to staff` 中的 `to staff`，即可看到 `staff` 的介词宾语标签。

在 `She said that he left` 中，引导名词性从句的 `that` 在默认视图中显示为连词。
在 `She has been studying` 中，即使折叠动词标签，`has` 的完成体助动词标签和 `been` 的进行体助动词标签仍会显示。

默认视图只保留一个用于展开相同详情的按钮，优先放在 `that` 等引导从句的连词上。可展开不同详情的标签各自保留按钮。

| 直接宾语       | d.o.     | token  | 直接受到动词动作影响的单词或短语             |
| 介词宾语       | prp.o.   | token  | 由介词引出的单词或短语                       |
